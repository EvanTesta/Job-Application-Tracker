# Job-Application-Tracker
The Job Application Tracker is meant for people who want to apply to many jobs but not have to manually enter the information into a spreadsheet. In the current day it takes an average of 100 to 200+ application to get a job. This number is likely increasing. It's important to keep track of everything you apply to, but it can be time consuming since you'd have to manually enter it into a spreadsheet. 
#### Requirements 
The Core Functionality 
- Copy a link and paste it into the site 
- The site will grab important information 
- The site will display this information and save it 
- The user can view all their applications 
- The user can click a button to download all their applications as a spreadsheet
- The user can input a spreadsheet of their own to be used 
#### Stretch Goals
- Self hosting 
- There are buttons for if they got an interview or job 
- Additional functionality to find jobs for the user
- Log In to store the user's jobs on the site
- The user can decide which information is stored, like if they want the salary or not
#### Tech Stack
 - Python (Beautiful Soup): Web Scraper 
 - Django: Web Framework
 - PostgreSQL: Database
